# Tableau data

These CSVs are what the Tableau Public dashboard is built on. They're generated by `src/export_tableau.py`, so rerun that if anything upstream changes.

| File | Grain | Used for |
|---|---|---|
| `orders_delivery.csv` | one row per delivered order (96,470) | KPI tiles, monthly trend, state map, review impact, filters |
| `monthly_kpis.csv` | one row per purchase month | quick check of the trend numbers |
| `state_performance.csv` | customer state | map tooltip numbers |
| `lane_performance.csv` | seller state -> customer state, lanes with 30+ orders | worst lanes chart |
| `category_performance.csv` | product category, 100+ orders | category chart |
| `model_monitoring.csv` | test month (Jan to Aug 2018) | predicted vs actual late rate, ROC AUC, precision@10% |
| `model_risk_deciles.csv` | risk decile on the test set | calibration chart |
| `model_feature_importance.csv` | feature | what drives the predictions (permutation importance, ROC AUC drop) |

## Columns in orders_delivery.csv

| Column | Meaning |
|---|---|
| `purchase_date`, `purchase_month` | when the order was placed (month is the 1st of the month so Tableau reads it as a date) |
| `customer_state`, `customer_state_name`, `customer_city`, `customer_lat`, `customer_lng` | where it was delivered |
| `seller_state`, `lane` | where it shipped from, and the origin -> destination pair |
| `category` | category of the most expensive item in the order |
| `items_price`, `items_freight` | order value and freight in BRL |
| `weight_kg`, `distance_km` | total weight, seller to customer distance (farthest seller if there are several) |
| `promised_days` | days between purchase and the estimated delivery date shown to the customer |
| `delivery_days` | days between purchase and delivery |
| `handling_days`, `transit_days` | approval -> carrier, carrier -> customer |
| `delay_days` | delivered date minus promised date, negative means early |
| `is_late` | 1 if delivered after the promised date |
| `review_score` | 1 to 5, blank if the customer didn't review |
| `model_split`, `late_risk`, `flagged_high_risk` | model output: train (2017) or test (2018), predicted probability of being late, and 1 if it's in the riskiest 10% |
